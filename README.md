## 📖 About

Retro Kicks is a full front-end e-commerce experience for a sneaker store — from browsing the catalog to checkout. It covers the complete shopping flow: product discovery, detailed product views, cart management, checkout, and user authentication, all built as a single-page React app.

---

## ✨ Features

- 🏠 **Home** — landing page highlighting featured sneakers and promotions
- 🛍️ **Shop** — browse the full product catalog
- 👟 **Product Detail** — dedicated pages with images, pricing, and details for each sneaker
- 🛒 **Cart** — add, update, and remove items before checkout
- 💳 **Checkout** — complete order flow
- 🔐 **Auth** — user sign-up and login
- 📱 **Fully Responsive** — works seamlessly on mobile, tablet, and desktop

## 🚀 Getting Started

### Prerequisites

- Node.js v18+
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/akshitbodrya-07/Retro-kicks-E-commerce.git

# Navigate into the project
cd Retro-kicks-E-commerce

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be running at `http://localhost:5173`

### Build for Production

```bash
npm run build
```
